# RSS-Bridges
This repo provides 2 RSS bridges for <a href="https://rss-bridge.org/">RSS-Bridge</a> app.

etfblBridge - Bridge that takes announcements from notice board site of <a href="https://efee.etf.unibl.org/oglasi/">Faculty Of Electrical Engineering in Banja Luka</a>. You can choose which section of announcements to keep track of (1st year, 2nd year, masters degree, etc...).
ArtixUpdatesBridge.php - Bridge that takes packages updates and moves based on Artix Linux maintainer. Uses <a href="https://checkupdates.artixlinux.org/">checkupdates site</a>.
